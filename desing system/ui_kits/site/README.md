# Site institucional — Por Onde Flor

Recriação de alta-fidelidade da home do e-commerce/site institucional. Componentes fonte (para reuso/dev): `Header.jsx`, `Hero.jsx`, `ProductGrid.jsx`, `Footer.jsx` — o `index.html` inlina a mesma estrutura para garantir execução standalone.

Interações reais: "Adicionar" em um produto incrementa o contador da sacola no header e mostra um toast de confirmação.
